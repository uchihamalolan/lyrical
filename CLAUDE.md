## Architecture

**Lyrical** is a full-stack React app for searching songs and viewing lyrics with AI transliteration, built on the TanStack ecosystem.

### Stack
- React 19 + TanStack Start/Router/Query
- Tailwind CSS + DaisyUI for styling
- Biome for linting/formatting
- Vitest for testing
- Deployed to Netlify

### Key Patterns

**Server Functions (TanStack Start):** Business logic runs server-side via `createServerFn()` with Zod validation. Located in `src/utils/`.

```typescript
export const searchSongs = createServerFn({ method: "GET" })
  .inputValidator(SearchQuerySchema)
  .handler(async ({ data }) => { ... });
```

**File-Based Routing:** Routes live in `src/routes/`. The `_app/` directory wraps content with the Navbar layout. Dynamic params use `$` prefix (e.g., `$songId.tsx`).

**Query Integration:** Routes use loader pattern with `context.queryClient.ensureQueryData()`. Query hooks/options defined in `src/queries/`.

**Server-Only Environment:** API keys validated in `src/config/env.ts` using `createServerOnlyFn()` to prevent client exposure.

### Directory Structure
- `src/routes/` - TanStack Router file-based routes
- `src/services/` - Business logic & external API clients (lrclib.net, Google GenAI)
- `src/utils/` - Server function wrappers
- `src/queries/` - TanStack Query configuration
- `src/components/` - React UI components
- `src/config/` - Environment configuration
